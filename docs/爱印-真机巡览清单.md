# 爱印工具箱 · 真机巡览清单（复刻第一手素材采集指南）

> 配套脚本：`aiyin_tour.py`（半自动截图器）。
> 目的：在你**本机**（能联网、爱印能正常显示）亲自用一遍每个功能/界面，
> 把「代码看不到的体验细节」——加载时序、hover 反馈、空状态、报错提示、拖拽手感、
> 动画过渡——截下来、记下来，作为比看代码更得心应手的复刻素材。
>
> 当前 WorkBuddy 沙箱**无法**让爱印画出窗口且联网被掐，所以这是给你自己机器用的方案。

---

## 0. 先跑脚本（三种模式）

```bash
# 1) 手动模式（推荐新手，最稳）：你点开功能 → 回车 → 脚本截爱印窗口
python aiyin_tour.py

# 2) 校准：依次点击 10 个工具图标，记录坐标（只做一次）
python aiyin_tour.py --mode calibrate

# 3) 自动：读取坐标，自动点开 10 个工具截图
python aiyin_tour.py --mode auto

# 仅看 10 工具清单
python aiyin_tour.py --list
```

- 截图默认存 `./aiyin_tour_shots/`，文件名带时间戳+标签。
- 依赖：`pip install pillow`（必需）、`pip install pyautogui`（calibrate/auto 需要）。
- 爱印路径不对就改脚本顶部 `EXE_PATH`，或设环境变量 `AIYIN_EXE`。

**采集完成后，把 `aiyin_tour_shots/` 整个目录发我**，我对照代码沉淀成《真机界面巡览报告》+ 补进复刻路线图。

## 2. 逐目标观察清单

> 每个目标记四类：**必截界面 / 必做操作 / 必记体验细节 / 复刻要点**
> 「必记体验细节」是代码最难还原、最该亲眼看的——重点记。

### 0. 主界面（工具网格）
- **必截**：首屏全貌、鼠标 hover 某个工具图标的态、侧边栏/顶栏、关于/设置入口、更新提示弹窗（若有）。
- **必做**：数一遍几个工具、图标排布（几行几列）、hover 有没有放大/高亮、点击后怎么进功能（新窗口？内嵌？）。
- **必记**：启动到可点用的耗时；首屏有无"加载中"骨架；工具图标的圆角/阴影风格；有没有 badge（如"新"/"AI"标）。
- **复刻要点**：clone 的导航是左侧分类+右侧卡片，对照看爱印原生是网格还是列表，差异记下来。

### 1. 证件照批量处理（本地）【已复刻，做"对照验证"】
- **必截**：拖入一批照片后的缩略图墙；点开单张的取景编辑器（含 6 个调整手柄）；换底色下拉；规格勾选面板；排版预览（相纸网格）；导出对话框。
- **必做**：拖入 3~5 张；改底色看实时预览；切规格看预览重排；调美颜滑块看过渡是否卡顿；导出 PDF 看结果。
- **必记**：批量导入的并发反馈（进度条？逐张出现？）；取景拖拽的跟手度；换底是否有"边缘锯齿/黑边"——这正是我们修过的点，看原版是否也有；导出等待时长。
- **复刻要点**：对照我们 `IdPhotoLeft/Center/Right.tsx` 三栏，原版是否也是三栏？取景手柄形状/交互是否一致？

### 2 & 3. AI 证件照 / AI 照片修复（AI，需微信登录）
- **必截**：未登录时的登录墙（二维码？）、登录后上传页、风格/参数面板、处理中动画、出片对比（原图 vs 结果）、下载/分享入口、积分扣减提示。
- **必做**：扫一次登录二维码（或看登录墙长啥样）；上传一张图走完流程（若不想真扣积分，截到"处理中"即可）；看积分变动。
- **必记**：登录态如何呈现（头像？积分数字？）；处理中转圈/进度是否真实；结果页有没有"放大对比"滑杆；按张计费的提示文案。
- **复刻要点**：这俩是服务端能力，clone 用开源替代。重点记**交互框架**（上传→处理→对比→下载），功能逻辑可抄、算法换开源。

### 4. 团拍助手（网页/联机）
- **必截**：相机联机配置页、名单（Excel/学号）导入、实时拍照归位到名单的示意、交付命名规则设置。
- **必做**：看是否能模拟联机（通常需真实相机，截到配置页即可）；导入一份名单看表格样式。
- **必记**：联机状态指示；拍照后自动归位到人头的动画；文件名模板编辑器。
- **复刻要点**：联机+人脸归位是重活，优先级低，先记交互骨架。

### 5. 证卡拼版助手（网页）【已复刻，做"对照验证"】
- **必截**：拖入身份证/户口本照片后的自动矫正结果（重点看四角圆角、去阴影）；正反面排同一张纸的预览；户口本跨页拆分拉直；扫描增强（拉白压黑）滑块；导出 PDF。
- **必做**：拖入一张拍歪的证件照，看自动找边+矫正的准确度；切正反面排版；调扫描增强看实时变化；导出。
- **必记**：**矫正前→后的过渡是否平滑**（我们加了椭圆圆角+渐显，看原版过渡方式）；矫正失败/需检查时的提示；多张卡同页的间距/边距；圆角是不是默认生效。
- **复刻要点**：对照 `cardCorrectMl.ts`（增强模型）与 `cardDetect.ts`（CV 回退）。原版的"需检查"阈值、圆角默认、边距常量，逐项记。

### 6. 图片拼版（网页）【已复刻】
- **必截**：拖入一堆截图后的 A4 顺序排版；长图自动分段+页码；间距/边距设置；导出。
- **必做**：拖入 10+ 张聊天截图看自动排序；放一张超长图看分段+页码；调边距。
- **必记**：排序规则（按文件名？拖入顺序？）；长图分段处的衔接提示；页码位置/样式。
- **复刻要点**：对照 `photoSheet.ts` 几何引擎，原版比例范围、边距、行列上限是否一致。

### 7. 批量制卡（网页）【部分复刻】
- **必截**：Excel 名单+照片导入、卡片设计器（拖字段/换模板）、整批套打预览、导出。
- **必做**：导入一份含照片列的 Excel；在设计器里加文字/图片字段；看套打预览。
- **必记**：字段绑定方式（拖拽？下拉？）；模板切换；照片缺失时的占位处理。
- **复刻要点**：`BatchCard.tsx` 主链路已有，记设计器交互差异。

### 8. 批量打印（网页）【已复刻】
- **必截**：拖入混合文件（PDF/图/Word）；页数+黑白彩色统计面板；报价明细；合并打印设置；打印进度。
- **必做**：拖入不同格式文件看统计如何聚合；看报价公式（每页单价？彩色加价？）；点合并打印。
- **必记**：统计是实时还是点"统计"按钮后出；报价是否可编辑；彩色/黑白识别准不准；打印队列进度呈现。
- **复刻要点**：对照 `PdfTools` 批量打印，原版报价口径、统计粒度记下来。

### 9. Office 转 PDF（本地）【已复刻】
- **必截**：拖入 Word/Excel/PPT；合并选项；PPT 讲义（每页几张）设置；输出列表。
- **必做**：转一份 PPT 看讲义排版；勾选多文件合并；看输出。
- **必记**：转换耗时（大文件）；失败提示（如缺字体）；讲义每页张数选项（2/4/6/9？）。
- **复刻要点**：clone 依赖本机 LibreOffice，记原版是否有同依赖、讲义选项全集。

### 10. 文件互传（网页/局域网）
- **必截**：设备发现列表、扫码传输入口（微信扫码）、传输进度、历史。
- **必做**：看设备如何被发现；扫码入口长啥样（无需真传）。
- **必记**：不经外网的提示文案；扫码后手机端流程（截不到可记文字）。
- **复刻要点**：局域网+扫码，优先级低，记交互骨架。

### S1. 设置
- **必截**：打印预设管理、默认纸张、默认打印机选择、常规（主题？自启？）、关于。
- **必记**：打印预设能否存多套；默认打印机怎么枚举；有没有"恢复默认"。
- **复刻要点**：对照 `print-settings-dialog` / `print-preset-manager`。

### S2. 模型管理
- **必截**：模型列表（名称/大小/状态）、下载进度、校验结果、本地占用空间、删除按钮。
- **必记**：首次启动是否自动下模型；41MB 户籍模型是否"按需"才下；下载失败提示。
- **复刻要点**：对照 `resources/card-model/` 与 `userData/models/runtime/*.bin`，原版下载/校验 UI 记下来。

### S3. 微信登录/账户
- **必截**：登录二维码、已登录头像/昵称、积分余额、权益/会员页。
- **必记**：积分如何展示；退出登录入口；离线 3 天限制提示（若有）。
- **复刻要点**：账户体系是服务端，记 UI 骨架。
