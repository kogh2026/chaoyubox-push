## 0. 一句话了解这个软件

爱印工具箱 = **Electron 外壳 + React 界面 + 一批「图片/证件/PDF/打印」处理工具**的桌面套件，主要客群是**图文店、照相馆、学校、企事业单位**，以及需要批量处理证件/照片/文档的个人。核心套路就一句：**拖入文件 → 自动处理 → 导出 PDF 或直接打印**，目标是"开店就能用、装上不联网也能干大部分活"。

## 1. 产品概述

### 1.1 形态与运行模型

| 维度 | 说明 |
|---|---|
| 安装包 | `爱印工具箱.exe`（Electron + 内置 React）；双击启动 |
| 工具数量 | **10 个**，分 3 大类：证件照 / 证卡与拼版 / 打印与文档 |
| 实现方式（原版 v0.5.0） | **真正本地实装 2 个**（证件照批量处理、Office 转 PDF）；**其余 8 个是官网网页（iframe 内嵌）**，需联网加载 |
| 隐私模型 | 本地工具不上传照片/文件；仅 `AI 证件照`、`AI 照片修复` 会把照片传服务器处理，需微信登录、按张扣积分，服务器 48h 删除 |
| 模型 | 本地 ML 模型**加密**（AES-256-GCM，见 §5.1）；首次后台下载约 50MB 处理组件；户籍模板模型 41MB **按需下载** |
| 授权/租赁 | 代码含 `desktop-lease-check`：连续离线最长 **3 天**，之后需联网一次 |
| 系统要求 | Windows 10/11（64 位）；macOS 12+；Win7 SP1/8/8.1 用兼容版 |

### 1.2 技术栈（原版）

- **外壳**：Electron（窗口管理、自定义协议 `aiyin://` 解密下发资源、打印机能力枚举、静默打印、文件系统原子写）
- **界面**：React + Vite 多入口产物
- **算力**：全部在前端 —— onnxruntime-web（wasm）、MediaPipe Tasks-Vision（TFLite）、opencv.js（wasm）
- **PDF**：jsPDF（矢量写入）
- **结论**：算力与逻辑都在前端，"打包成 Electron"只是补最后 5%；复刻可以**完全先跑在浏览器里**，再包壳。

## 5. 技术架构与引擎分工

### 5.1 资产加密体系（原版技术壁垒，复刻无需触碰）

```
文件 = "AYE1"(4B) + IV(12B) + GCM tag(16B) + 密文
算法 = AES-256-GCM
密钥 = hkdfSync("sha256", M7hex, salt="aiyin/desktop-asset/v1", 32)   // M7 硬编码 64 位 hex
IV   = HMAC-SHA256(key, 相对路径 ‖ 0x00 ‖ sha256(明文))[0:12]
AAD  = 资源相对路径
```

主进程用 `registerStreamProtocol` 注册自定义 scheme 解密下发；白名单仅 `assets/*.js|css`、`assets/runtime/*.bin`、`vendor/*.js`，**明文资产会被拒收**。

### 5.2 模型资产清单（4 个，复刻一律替换开源等价物）

| ID | 大小 | 格式 | 角色 | 复刻替代 |
|---|---|---|---|---|
| `11680454…` | 13.0MB | ONNX fp16 | 抠图 matting-v1（实为开源 MODNet 的 fp16 打包） | 开源 MODNet/ISNet/u2net ONNX |
| `c6748b12…` | 16.4MB | TFLite | selfie-multiclass 多类人像分割 | MediaPipe 官方 `selfie_multiclass_256x256.tflite`（Apache-2.0） |
| `1162e85b…` | 53.6MB | ONNX | retouch-v1 匀肤（**私有权重**） | 开源美颜或自训；管线逻辑可复用 |
| `64184e22…` | 3.7MB | ZIP | MediaPipe Face Landmarker 官方任务包 | 官方开源同款 |

> 结论：爱印真正的私有资产只有**抠图权重**（但它就是 MODNet）+ **匀肤权重**两份；其余（MediaPipe 两模型、onnxruntime、opencv、管线编排）全部有开源等价物。

### 5.3 拼版几何引擎（最该照抄的设计）

- **几何全部以 mm 为单位算出，出图时才乘 DPI** —— 这是"预览 = 导出 = 打印"的根本原因。
- 纯函数 + 位图：几何只在 `photoSheet.ts`，渲染只在 `photoSheetRender.ts`，PDF 整页位图写满纸。
- 关键常量（爱印值，已照抄）：页边距 10mm、图注行高 6.8mm、正文字号 4.2mm、页码 7mm、间距上限 10mm、行列 1~6、宽高比钳制 0.3~2.3。
- 长图自动分段：逐行空白检测（差异 >14 且低于宽×0.4% 判空白）→ 窗口搜索连续空白区间切点 → 不切断文字行。

### 5.4 证卡矫正引擎

- **CV 路径**（`cardDetect.ts`）：Canny 粗定位 → 梯度亚像素精修 + RANSAC → 验收（paper≥0.65 & ink 0.004~0.55）→ NEED_CHECK=0.6。
- **增强模型路径**（主路径，`cardCorrectMl.ts`）：`card-correction-fp32.onnx`（输入 `[1,3,768,768]`，中心双线性 + 标准化；后处理阈值 .3/.03、NMS、angle%4 环移、单应+旋转+涂白）。
- 两条路径**互斥**，不重复内缩。
- 越界像素填**白色**（不是黑），残留黑边来自"四角外侧的暗色内容"——故用 0.8% 内缩解决。

## 8. 复刻合规边界（务必遵守）

1. **只复刻行为与规则**：几何、阈值、交互、业务流程可以照抄实现，不复制加密资产、不内置爱印模型权重、不使用其商标与图标。
2. **模型全替换**：抠图用开源 MODNet/ISNet；人像分割用 MediaPipe 官方 TFLite（Apache-2.0）；匀肤/修复用开源或自训；Face Landmarker 用官方开源包。
3. **品牌独立**：界面文案与版式可对齐观感，但不逐字复制品牌语；保留自有产品名与图标（现名"超誉工作台"）。
4. **资产零改动**：原安装文件不移除/不绕过运行时保护，解密产物不用于再分发。

## 9. 关键结论

- 爱印**真正私有的只有两份模型权重**（抠图=MODNet fp16、匀肤 retouch-v1）；其余全是开源库或纯业务逻辑，**1:1 复刻在能力上完全可行**。
- 差距主要落在三块：**匀肤质感**（学习型网络）、**自动构图引擎**（6 度量 + quad 求解，已复刻）、**编排层**（状态机/批量/多尺寸导出）。
- 当前 `aiyinbox-clone`（超誉工作台 v0.0.12）已完成本地工具链的绝大部分，并通过 tsc / 单测（771+）/ build / UI 回归门禁。下一步按《复刻路线图》补齐 AI/联机与工程化即可达到"全功能复刻"。
