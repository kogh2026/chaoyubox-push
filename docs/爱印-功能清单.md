### 2.2 PDF 工具箱（48 项子功能）

原版"PDF 工具箱"是一个聚合入口，内含约 **48 项**离线 PDF 处理功能。按用途归类如下（名称取自复刻版 `src/tools/pdf/defs.ts`，与爱印一一对应）：

| 分组 | 功能项 |
|---|---|
| **页面管理** | 页面管理、整理页序、颠倒页序、奇偶页分离、补齐偶数页、旋转页面、统一页面大小、删除页面、提取页面、删除空白页 |
| **版式拼版** | 版式拼版、N-up 拼版、骑马订拼版、书籍折页拆分、对开页切分、裁切白边、纠正倾斜 |
| **合并与拆分** | 合并文档、交叉合并、拆分文档、按书签拆分、书签生成文件、固定页数拆分 |
| **格式与图像** | 图片转 PDF、新建空白文档、导出为图片、提取内嵌图片、转为图片版、黑白灰度化、图纸蓝底化 |
| **标注与编号** | 标注编号、添加页码、贝斯编号、接缝标记 |
| **安全与信息** | 加密文档、解除加密、文档属性、签名检查 |
| **优化** | 压缩优化、扁平化处理 |
| **水印与批注** | 文字水印、图片水印、添加批注 |

> 复刻版当前已有 48 项 defs 的完整骨架与多数处理逻辑；其中"文档属性 / 签名检查"由面板自带按钮完成（原版"执行"是死桩已修）。

### 2.3 应用级功能（不在工具网格里，但属于程序自身）

| 功能 | 说明 |
|---|---|
| 微信登录 / 账户与积分 | 用 AI 功能前登录；积分用于 AI 证件照/修复按张扣 |
| 模型管理 | 查看/下载/校验本地加密模型（首次 ~50MB，户籍模型 41MB 按需） |
| 设置 | 打印预设、默认纸张、默认打印机（`print-settings-dialog`、`print-preset-manager`） |
| 自检 | 内置示例文件（`self-test-*.xlsx/.pptx/.docx`）跑通 Office 转 PDF/打印链路 |
| 授权 / 租赁校验 | 离线最长 3 天限制的来源 |
| 使用统计 | 本地用量（`desktop-usage`） |
| 商户设置 | 门店品牌/水印（`shop-settings-panel` / `shop-images`），面向图文店 |
| 更新机制 | 应用内提示，点更新下载，退出时自动装好 |
