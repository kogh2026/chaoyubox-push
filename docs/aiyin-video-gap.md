## 0. 一句话结论

这批视频**不能直接当"素材"用**（是手机拍屏幕的竖屏短视频，有反光、摩尔纹、水印、口播遮挡），
但**能当"说明书"用**——它们提供了原软件真实的字段名、分组顺序、按钮位置和交互顺序。
可提炼出的可执行改动集中在 **证卡拼版（拼版设置 + PDF 预览）** 和 **证件照（换底色/输出设置）** 两块；
**AI 换装 / AI 生成**这类功能属于模型能力，视频只能证明"有"，无法据此复刻。

## 2. 提炼出的事实情报（按工具）

### 2.1 证卡拼版 / 证卡裁切排版助手（v04、v05）

**右栏设置分组（自上而下）**

1. `☐ 一张图有多张证卡` — 副标题「勾选后自动拆分成多张证件」
2. `每页张数` — 1 张 / 2 张 / 3 张 / 4 张（v04）；
   v05 的版本是**排版缩略图**形式，可选 2 / 3 / 5 / 6 / 11 张，缩略图画出了实际排布
3. `色彩模式` — `增强` / `灰度扫描` / `原色`
4. `阴影与反光去除` — 0–100% 滑杆（实测 50%），左端 `自然`，右端 `打印优化`
5. `纸张尺寸` — `A4 210×297` / `Letter 215.9×…` / `A3 297×…`（标题右侧显示当前 `210 x 297 mm`）

**左栏列表项（v05）**

- 每项：勾选圆点 + 右上角状态角标 `可导出`
- 缩略图、文件名（如 `473c9bc336324a98…`）、文件体积（`1.4 MB`）
- 一行 `▣ 身份证  85.6 x 54 mm ▾` — 证件类型下拉，**带规格尺寸**
- 底部小图标：上移 / 下移 / 删除（判读为 3 个）
- 画布上每张卡左下角有 `1-2 / 1-3 / 1-4` 编号（第 1 页第 N 张）

**画布顶部操作条（v05）**：`+ 添加照片` ｜ `⤓ 导入顺序 ▾` ｜ `清空`（红色文字按钮）

**PDF 预览弹窗（v04，重要）**

- 标题：`PDF 预览` + 副标题 `共 2 页 PDF`
- 顶栏按钮：`⤓ 保存`（主按钮）、`适合页面`、`100%`、`🔍 59% ▾`（缩放）、`✕`
- 左侧：页缩略图列（1、2，当前页高亮）
- 中间：页面画布
- 右侧：拼版设置面板**保持可用**（边预览边调设置）

### 2.2 证件照批量处理（v06、v07、v08）

**左栏**：`导入照片`（主按钮）、`N 张演示照片`、`已选 6 / 6` + 宫格/列表切换图标、缩略图多选

**中间**：大预览 + 裁剪框 + 拖拽缩放 + 滑杆；顶部右侧 `👁 按住查看原图`；
标注实际尺寸文案 `22 mm` / `378 px`

**右栏（v06、v07 三页签）**

- 页签：`抠图` / `尺寸` / `排版`（v07）；`排版` 页顶部有 `← 返回证件照编辑`
- `1 尺寸` — 副标题「选择用该模板，批量应用到已勾选照片」；规格卡 `小一寸照 22 × 32 mm · 260 × 378 px`
- `2 背景` — 副标题「统一换底色，并选择人物边缘处理质量」；色块：蓝（选中）/ 红 / 白 / 透明 / 自定义
  → `抠图质量`：`◉ 标准（推荐）` `○ 精细发丝`
- `3 输出` — `导出内容 ☑ 单张`、`单张设置 → 分辨率 300 DPI`、`单张文件大小 20~200 KB`、
  `排版设置 → 相纸尺寸 5 寸 · 127 × 89 mm`
- 排版页顶部信息条：`… 300 DPI 与导出一致，间隔 2 mm`、`* 89 mm · 单人分纸`、
  `适应` / `1:1` / `🔍 200%` / 翻页 `6 / 6 页`

### 2.3 批量打印（v08）

未出现新结构；与已复刻的版本一致（列表 + 预览 + 底栏报价）。

### 2.4 AI 证件照（v09）— 只能提取"能力清单"

- 自动识别 `性别` / `年龄`（界面显示 `人像：男 / 年龄 24`）
- 换装：一套男/女正装缩略图（西服、衬衫领结），点选后生成

- 结论：**属于模型/素材库能力**，视频不含任何可复用参数。

## 3. 与 clone 现状的差距 + 判定

| # | 爱印的做法 | clone 现状 | 判定 | 说明 |
|---|---|---|---|---|
| 1 | 色彩模式 `增强/灰度扫描/原色` | `增强/黑白/彩色` | **能用** | 纯文案对齐，0 风险 |
| 2 | 纸张 `A4/Letter/A3` | `A4/A5/A3` | **能用** | 补 Letter(215.9×279.4)，保留 A5 做超集 |
| 3 | 每页张数以**排版缩略图**呈现（2/3/5/6/11 张） | 数字档位 1–4 + 「放不下缩小」 | **谨慎用** | 需把"档位"升级为"版面预设"，牵动 `pagePlacements` 网格计算 |
| 4 | `阴影与反光去除` 0–100% 滑杆 | 有 `饱和度/锐化` 滑杆 | **谨慎用** | 要真做需加去阴影算法（Retinex/背景归一），只加滑杆=假控件 |
| 5 | `☐ 一张图有多张证卡` 显式开关 | 增强模型**始终**自动拆多卡 | **能用** | 加一个"是否拆分"的入参到检测管线 |
| 6 | PDF 预览弹窗（页缩略图/适合页面/缩放/保存） | 直接下载 PDF，无预览 | **能用** | 中等工作量，纯前端渲染，不动排版引擎 |
| 7 | 列表项显示 `文件体积` + 类型下拉带 `85.6 x 54 mm` | 有状态角标/上下移/删除，无体积、类型无尺寸 | **能用** | 低风险补信息 |
| 8 | 画布顶部 `添加照片 / 导入顺序 / 清空` | 工具条在左栏 | **能用** | 位置迁移，注意不重复入口 |
| 9 | 证件照 `抠图质量：标准 / 精细发丝` | 有抠图/匀肤，无"发丝级"档 | **谨慎用** | 需要第二套精细抠图模型，否则只是换文案 |
| 10 | 证件照 `单张文件大小 20~200 KB` 约束 | 有 DPI / 像素，无输出体积约束 | **能用** | 用 JPEG 质量二分逼近目标体积 |
| 11 | AI 换装（西服/衬衫领结） | 无 | **不能用**（本期） | 需服装素材版权 + 人像合成，风险与成本高 |
| 12 | AI 生成（识别性别年龄后重绘） | 无 | **不能用**（本期） | 需扩散模型 + 合规评估，且视频无参数 |

## 4. 复刻思路（建议排期）

### Phase V1 · 证卡拼版「设置项对齐」（低风险，先做）

- `src/lib/idCardLayout.ts`
  - `ColorMode` 文案：`'bw'` → 显示「灰度扫描」，`'color'` → 显示「原色」（枚举值不变，只改 UI 文案）
  - `PaperId` 增加 `'letter'`，`IC_PAPERS` 补 `{ w: 215.9, h: 279.4, name: 'Letter' }`；
    纸张按钮顺序改为 `A4 / Letter / A3`（A5 保留在末位或下拉"更多"里）
- `src/tools/CardLayout.tsx`
  - 纸张按钮渲染改为读取 `IC_PAPERS` 顺序，而不是硬编码 `['a4','a5','a3']`
  - 列表项补「文件体积」（`dataUrl` 长度 × 0.75 估算 KB/MB）
  - 类型下拉的选项文案追加规格尺寸：`身份证 85.6×54 mm`
- 验收：`tsc` + `cardLayout` 单测 + 目视三档纸张切换不错位

### Phase V2 · 证卡拼版「PDF 预览弹窗」（中风险，价值最高）

- 新增 `src/tools/CardPdfPreview.tsx`（或 `src/components/`）
  - props：`pages: {canvas}[]`、`onSave`、`onClose`
  - 结构：页缩略图列（左）+ 画布（中）+ 缩放工具条（`适合页面 / 1:1 / 百分比`）
  - 复用现有 `renderAll(EXPORT_DPI/25.4)` 的产物，不重复渲染
- `CardLayout.tsx`：`已导出 → 先弹预览 → 用户点「保存」才落盘`
- 注意：右侧设置面板在预览态仍可改（改完重新渲染页面，保留页码位置）
- 验收：页数=排版页数；缩放不糊（按设备像素比绘制）；`Esc` 关闭

### Phase V3 · 证卡拼版「版面预设（缩略图选张数）」

- `idCardLayout.ts`：把 `perPage` 数字档升级为 `layoutPreset`（含每页张数 + 行列 + 是否允许跨行）
- `pagePlacements` 支持预设给出的显式行列，而不是"按纸张算最大网格"
- UI：右栏「每页张数」换成缩略图按钮，缩略图用 canvas 小图实时画（复用现有几何函数）
- 风险点：与「放不下自动缩小」「圆角」「水印」组合时的边界，需要补单测

### Phase V4 · 证件照「输出体积约束 + 抠图质量档」

- `20~200 KB`：导出 JPEG 时按体积二分调质量（`quality` 0.99→0.5 迭代 6 次）
- `标准 / 精细发丝`：先做 UI 分层，接第二套精细抠图模型需另立任务
- 验收：导出体积落在区间内；不满足时给明确提示而不是静默失败

### Phase V5（不建议本期）· AI 换装 / AI 生成

- 需解决：服装素材授权、人物姿态对齐、生成一致性、合规审核
- 建议作为独立立项，而不是"界面复刻"的一部分

## 5. 已确认的取舍（2026-11-03）

1. **A5 保留**：纸张排布为 `A4 / Letter / A3 / A5`——前三个与爱印一致，A5 作为额外档位排在最后。
   实现见 `IC_PAPER_ORDER`（`src/lib/idCardLayout.ts`）。
2. **导出前预览：默认开**，可在右栏「导出」分组关掉（`localStorage: chaoyu.idcard.previewBeforeExport`）。
   `Ctrl/Cmd+S` 始终直接落盘，不走预览（快捷键语义就是「存」）。
