## 3. 界面交互说明

### 3.1 总体导航

- **启动**：双击 `爱印工具箱.exe`。首次启动后台拉取工具目录 + 下载本地模型（约 50MB，看网络）。
- **主界面**：顶部/侧边是**工具网格**，按 3 大类分组展示（证件照 / 证卡与拼版 / 打印与文档），点任一工具卡片即打开。
- **应用级入口**：角落或侧栏有微信登录、设置、模型管理、自检、授权状态、使用统计、商户设置、更新、反馈诊断导出。
- **排错**：任意界面按 `Ctrl+Shift+I` 打开开发者工具看 Console/Network；应用内"反馈/诊断"可一键导出日志（`exportDiagnostics`）。

### 3.2 各工具交互要点

| 工具 | 典型交互流程 |
|---|---|
| 证件照批量处理 | 拖入照片（可多张）→ 选底色、选尺寸规格 → 可选美颜/调光 → 预览合成 → 导出 PDF 或选打印机直打。换底实时预览；同规格多张自动拼到一张相纸 |
| 证卡拼版助手 | 拖入正反面照片 → 自动识别+矫正（边缘检测/增强模型）→ 选纸张（A4/A5/A3）→ 导出/打印。圆角、色彩、水印可调 |
| 图片拼版 | 拖入截图 → 自动按序编号、长图分段 → 预览 → 导出/打印 |
| 批量制卡 | 准备 Excel 名单（含照片路径）→ 设计卡片模板 → 批量套打 → 导出/打印 |
| 批量打印 | 拖入文件 → 统计页数、区分黑白彩色、算报价 → 合并打印。含打印预设、测试页、报价 |
| Office 转 PDF | 选 Word/Excel/PPT → 转 PDF（可合并；PPT 可排讲义）→ 输出。**前提：本机装 LibreOffice**，否则提示引导安装 |
| PDF 工具箱 | 选一个子功能 → 拖入 PDF/图片 → 设置参数 → 执行 → 下载/进批量打印 |
| PDF 预处理 | 合并/拆分/旋转/统一页面大小，结果直接进批量打印 |

### 3.3 复刻版交互增强（已做）

- **工具页 keep-alive**：首次进入后保持挂载，切走用 `display:none` 隐藏，避免状态丢失与回看卡顿。
- **全局过渡动画**：按钮/卡片/侧栏 hover + 按压反馈；弹层 fade/zoom 入场；spinner 加载态；进度文字成功绿/失败红。
- **全局键盘焦点环** `:focus-visible`；原生 `select` 美化；深色主题适配。
- **证卡缩略图椭圆圆角 + 加载过渡**：圆角 `12px/9px` morph 入场；照片解码即显示"识别中"占位，矫正完成后原地替换为规整卡面（首屏 45ms）。
- **裁切去黑边**：自动校正路径四边形角点内收 0.8%，消除卡边外侧残留暗边。
