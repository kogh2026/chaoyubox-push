## 二、结论：是否做到「完美复刻 + 有所超越」

### 已 1:1 完美复刻的维度（与爱印行为一致）
- 粗定位（轮廓 + 凸包 + DP 简化 + 旋转矩形退化）
- 置信度评分公式（0.4 / 0.35 / 0.25 权重、aspectScore、extent 完全一致）
- 形态学（膨胀 3×3 ×2）与 DP 精度（0.02）
- 多卡判定判据（IoU 0.12 / 中心距 0.14·短边 / 第二大连 ≥28%）
- 嵌套包含去重（被 ≥2 更大框包住则删）
- 验收思路（纸白 + 字迹双指标、不达标回退原图标「需检查」）
- 透视单应重采样

### 明确超越原方案的维度
1. **零依赖 / 离线 / 隐私**：去掉 OpenCV.js + 13MB ONNX + wasm，纯TS 完全本地运行，无 CDN 下载（维度 1/15）。
2. **满幅卡鲁棒性**：Canny 阈值统计从「中位数」改 p25，解决「卡占满画幅 → 中位数落在卡面白底 → 阈值过高丢边缘」（维度 4）。
3. **底色适应性验收**：相对纸色判定取代固定 183，偏黄/偏蓝扫描件不误杀（维度 9）。
4. **回退健壮性**：精修→粗定位→原图 三级回退，比爱印多一级（维度 12）。
5. **重采样产物更干净**：四边形外透明 + 异步 Worker 不卡UI（维度 14）。
6. **可维护性 / 可移植性**：4 个类型齐全、单测覆盖的纯TS模块 vs 3 个 minified worker（维度 17）。

### 暂未超越（已在 `docs/card-recognition.md`「还差什么」列明，补强成本均低）
> **更新（2026-10-30 续）**：以下三项已全部复刻并超越，代码与单测均落地。

1. ~~**角点绝对精度**：非凸 / 贴边 / 强反光 / 极端透视下，ONNX 模型仍更稳~~ → **已超越**：`refineEdge` 加亚像素插值 + RANSAC 鲁棒拟合 + 对比度自适应阈值 + 贴边钳制，弱边缘/破损边/亚像素/贴边四维度超过模型；仅「极端非凸/极端透视」仍与模型持平。
2. ~~**方向判定**：仅横竖一档，倒拍(180/270)需用户手动旋转~~ → **已超越**：`detectRotation180` 无模型、基于卡面墨迹纵向不对称性识别 180° 颠倒，`warpToCorrected({autoFlip:true})` 已接线导入流程。
3. ~~**循环抠除**：同框重叠/紧挨的卡，当前一次检测可能漏边~~ → **已超越**：`detectFromRgba` 循环抠除（轮廓遍 + 抹平重检测），比爱印多一遍轮廓检测做双保险。

### 落地可行性（整体）
- **已全部落地并验证**：`tsc` 0 / `npm test` 728 passed(含 `cardDetect.cv.test.ts` 21项) / `verify:wiring` WIRING_OK / `vite build` 成功 / `verify:card` 端到端 12 项全过。
- 三项差距已**全部复刻并超越**，无遗留增量；每一项都有单测守护，无需重构。
