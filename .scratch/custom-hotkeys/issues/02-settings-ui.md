# 02: 设置中心快捷键页重写（可录制/冲突/恢复默认）

**What to build:** 设置中心「快捷键」子页从静态展示表变成可编辑表格：每个动作一行，显示友好键名、「录制」按钮进入捕获态（按键即绑定，Esc 取消，纯修饰键拒绝并保持捕获）、冲突时行内红字指出冲突动作且不落库、逐行「恢复默认」+ 顶部「全部恢复」。改动存 localStorage 并经 CustomEvent 广播，改完即生效、刷新后保留。用户视角：键位终于能改了，改错有保护，能复原。
